# 砺儒云课程播放助手

> 华南师范大学砺儒云课堂（`moodle.scnu.edu.cn`）的油猴脚本：**整门课的视频清单 + 队列连播 + 进度监控 + 面板化操作**。
> 点开一门课就能看到这门课到底有多少节视频、各自看到哪了，不用一节节点进去看；
> 面板上随时能看到"现在播到哪、还差多少"。

- **版本**：`1.0.0`（首个公开版本）
- **安装文件**：本目录下的 [`LiRuYun-CoursePlayer.user.js`](./LiRuYun-CoursePlayer.user.js)
  —— 文件名就是它的正式名（CoursePlayer = 课程播放助手）；装进 Tampermonkey 后列表里显示的是
  `@name`「砺儒云课程播放助手」
- **使用说明**：[`使用说明.md`](./使用说明.md)（每一步做什么、每个开关什么效果、出问题先看哪里）
- **适用页面**：`https://moodle.scnu.edu.cn/*`（fsresource 视频页、h5pactivity、课程页）
- **许可证**：[MIT](./LICENSE)

## 一、安装

### 方式 A：从 GitHub 一键装（推荐，能自动更新）

安装链接（就是仓库里那个 Raw 地址）：

```
https://raw.githubusercontent.com/TreehaoL/LiRuYun-CoursePlayer/main/LiRuYun-CoursePlayer.user.js
```

1. 浏览器里先装好 [Tampermonkey](https://www.tampermonkey.net/) 扩展；
2. 打开上面的链接；
3. Tampermonkey 会自动识别并弹出安装页 → 点「安装」；
4. 回到砺儒云页面**刷新一次**。

脚本头部带了 `@downloadURL` / `@updateURL`，都指向这个地址，所以**以后仓库里的 `@version` 一变大，
Tampermonkey 就会自动提示更新**，不用再手动重装。

### 方式 B：手动粘贴

1. 浏览器里装好 [Tampermonkey](https://www.tampermonkey.net/) 扩展；
2. 打开 Tampermonkey 面板 → **添加新脚本**；
3. 把 `LiRuYun-CoursePlayer.user.js` 的**全部内容**粘贴进去（覆盖模板里的示例代码）→ `Ctrl+S` 保存；
4. 回到砺儒云页面**刷新一次**。

> 仓库根目录的结构与本目录一致：`.js` 与几份文档在根目录，`可选-纯逻辑版/` 是子目录。


### 同一时间只装一个

本仓库提供两个文件，**功能逻辑完全一样**，区别只在界面：

| 文件 | 说明 |
| --- | --- |
| **`LiRuYun-CoursePlayer.user.js`**（本文件，推荐） | `@name` = **砺儒云课程播放助手**。面板分页 + 列表常驻，操作集中在一个面板里 |
| `可选-纯逻辑版/LiRuYun-v3.user.js` | `@name` = 砺儒云播放助手 v3 · 安全 / 暴力 双模式。逻辑一样，**界面不重排** |

- **只装一个**。两个都装，同一页会各建一个面板、互相抢播放器。
  （它们之间带让位机制：带面板的正式版优先、另一个自动让位，所以一般不会看到两个面板；
  但没必要同时装。）
- 想换成不带面板重排的版本？把 `可选-纯逻辑版/LiRuYun-v3.user.js` 拖进 Tampermonkey 即可，
  它和正式版不会互相干扰（会互相让位）。

## 二、它解决什么问题

| 痛点 | 这个脚本做的事 |
| --- | --- |
| 视频分散在几十个章节里，看不出这门课到底有多少节、哪些没看 | 自动把整门课的**视频清单**（含每节进度、`已完成` 标记）列出来，点一行直接跳过去 |
| 一节看完要手动点下一节 | 队列连播：达标自动切下一节（可关）；每节看完的进度会落到本地记录 |
| 页面进度读数和"能不能进下一节"对不上 | 直接读课程页的完成要求（默认 90%）与真实进度，达标才推进；**不拿页面上的"已完成"字样当判据** |
| 播放停住 / 画面冻住没人管 | 停摆看护 + 冻帧看护：暂停了会试着恢复，画面不动会重新 play 并轻微 seek 唤醒 |
| 学习确认弹窗卡住播放 | 自动完成学习确认（多事件类型自适应），之后恢复播放 |
| 站点动不动弹原生弹窗挡路 | 拦下站点原生 `alert`（"禁止同时观看多个视频"那类），并顺手恢复被站点暂停的播放 |
| 想一段时间不看又怕它乱跑 | 定时暂停（每隔 N 分钟停 M 秒）、⏹ 急停（一键停止并暂停，且不会被自动恢复） |

## 三、界面一眼看懂

```
标题栏：视频标题 · 当前进度/达标线            —  ◎  ⟲
[🛡 安全模式] [⚡ 暴力模式]        ← 两个模式各占一页
[扫描][刷新列表][只看未完成]  [▾ 列表]  [⚙ 设置]  [⏹ 急停]
┌ 视频列表（可拖动分隔条调高度）───────────────┐
│ 1 视频2.1 ……  ▓▓▓▓░ 92%  已完成            │
│ 2 视频2.2 ……  ███░░ 30%  30% ← 在看=黄色    │
└──────────────────────────────────────────┘
[⏮] [▶ 播放 / 重播] [⏭]
──── 当前模式页（安全=队列设置；暴力=发包参数）────
┌ 日志（可滚动查看历史，可拖动分隔条）──────────┐
└──────────────────────────────────────────┘
```

- **设置窗口**（`⚙ 设置`）只放偏好：面板透明度、自动静音、弹窗拦截、完成后是否自动下一节、自定义达标进度。
- **日志**在主窗口底部：可滚动看历史、默认跟随最新、往上翻时不会被打断（点行数回到底部）。
- **三处尺寸都能自己调**：**列表高度**、**日志高度**（两根分隔条）、**面板大小**（右下角手柄），
  调完就记住，刷新后照旧。

## 四、安全模式与暴力模式

- **安全模式**（默认）：就是"正常播放 + 自动连播 + 进度监控"。不向服务器发任何额外请求。
- **暴力模式**：直接向 `mod_fsresource_set_time` 连续上报观看时长，把进度"刷"到达标。
  **默认关闭，且需要手动确认。**

> ⚠ **暴力模式的风险请自己评估**：它会让学校服务器收到异常请求，可能被风控记录，
> 也可能与课程 / 学校的学术诚信要求冲突。作者不对使用后果负责。
> 脚本里为此保留了三道闸门：① 默认关闭；② 启动前确认框（确认一次只在**当次会话**内免问）；
> ③ 达标即停 / 次数上限 / 连续失败即停。

## 五、常见问题（详见 `使用说明.md`）

| 现象 | 怎么办 |
| --- | --- |
| 列表少了几节 | 点 `刷新列表`（会展开折叠章节 + 读服务端接口）；仍不对就把 `__liruyun.listInfo()` 的输出发出来 |
| 刷到 100% 了但我这还显示没完成 | 页面读数是滞后的，脚本会自动"暂停 / 播放"催一次刷新；控制台也可 `__liruyun.bruteApi().nudge()` |
| 站点弹窗又出现了 | 那是站点原生弹窗，脚本已尽量拦；若日志出现「页面被原生弹窗卡住」，说明这次没拦住 |
| 面板挡住画面 | 拖走 / 缩小 / 调透明度 / 点 `◎` 收成悬浮球 / 点 `—` 收成一条标题栏 |
| 列表和日志太挤或太空 | 拖**列表下面**那根分隔条调列表高度、拖**日志上面**那根调日志高度，松手即记住 |
| 想只看没看完的 | 点 `只看未完成` |
| 想立刻停一切 | 点 `⏹ 急停`（停止队列与发包并暂停视频，且不会被自动恢复；点播放即可恢复） |

## 六、控制台速查

```js
__liruyun.snapshot()          // 当前状态（进度、阈值、队列、播放状态）
__liruyun.listInfo()          // 视频列表是怎么扫出来的（条数/来源/候选容器/服务端兜底）
__liruyun.refreshList()       // 强制重扫列表
__liruyun.prefs()             // 播放偏好（完成后是否下一节 / 达标进度 / 连播 / 急停）
__liruyun.dialogInfo()        // 弹窗拦截统计（拦了几条、被卡住几次）
__liruyun.proUi().where()     // 每个控件现在挂在谁身上（排查"某个东西不见了"）
__liruyun.proUi().layout()    // 面板各区域尺寸（排查"被挤没 / 滚轮怪"）
__liruyun.proUi().logH()      // 看 / 设日志区高度（等价于拖那根分隔条）
__liruyun.proUi().listH()     // 看 / 设视频列表高度（等价于拖那根分隔条）
__liruyun.bruteApi().ack()    // 暴力模式风险确认状态
__liruyun.bruteApi().nudge()  // 手动催一次页面进度刷新
```
